# 身体行走原画制作方式

用户要求整款游戏全部美术完成，并此前授权“按你自己做”、后续使用本项目原创资源。当前宿主只有静态image_gen，未提供图生视频入口；本次不启用任何付费API、订阅、凭据或他人F盘素材。

人物动作采用逐姿势独立AI原画：每个身份4个完整身体姿势，均直接参考同一个已确认本项目母图，分别绘制左脚接触、经过、右脚接触、经过。漂浮角色按身份改为4个真实不同的纸带/悬挂/肢体运动姿势，不凭空添加腿。逐张调用并保存完整提示词、实际输入及回执，再以共同身体尺度和固定画布技术注册。不是单张图平移、缩放、淡出的伪帧，也不是图生视频，不称流体视频动作或原生更高分辨率。镜像只表示左右，非新增后视图。

video2dsprite的默认“一母图一动作视频”路线在media-doctor.json证实为none。本次在用户自主制作授权内，以宿主静态编辑逐张画动作关键姿势，避开整张角色序列图集的身份/切格风险。已有视频处理工具不被说成视频生成工具。此方式的4帧关键姿势循环必须实际播放后才验收；没有经过的组保持未完成。它是风格化逐帧动作，不宣称与连续视频同等流畅。

动作母图不得更换角色面孔、服装、武器或颜色，不写文字或背景。所有新图仅在本阶段新路径；不改既有母图和UI。出现换脸、缺肢、静帧重复或循环失败时重画具体问题姿势，不能为完成数而通过。
